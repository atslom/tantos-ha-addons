Настройки

Сущность — любая: очистите поле и начните вводить, появятся подсказки (alarm_control_panel, input_boolean, binary_sensor, switch), либо впишите свой entity_id. Пусто = выключить. «Снято с охраны»: для панели — disarmed, для переключателя/сенсора — off. Всё остальное считается «на охране».
